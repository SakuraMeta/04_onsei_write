# 🎤 リアルタイム音声文字起こしアプリ

Webブラウザのマイクを使用してリアルタイムで音声を文字に変換するアプリケーションです。

## ✨ 機能

- **リアルタイム音声認識**: マイクからの音声をリアルタイムで文字起こし
- **日本語対応**: 日本語音声の高精度認識
- **Webベース**: ブラウザで動作、インストール不要
- **美しいUI**: モダンで使いやすいインターフェース
- **タイムスタンプ**: 各文字起こし結果に時刻を表示

## 🚀 クイックスタート

### 1. 自動セットアップ（推奨）

```bash
# start.batをダブルクリックするか、以下のコマンドを実行
start.bat
```

### 2. 手動セットアップ

```bash
# 1. 仮想環境の作成
python -m venv venv

# 2. 仮想環境のアクティベート
venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux

# 3. 依存関係のインストール
pip install -r requirements.txt

# 4. アプリケーションの起動
python app.py
```

## 📋 必要な環境

- **Python**: 3.7以上
- **マイク**: 音声入力デバイス
- **ブラウザ**: Chrome、Firefox、Edge等（マイクアクセス対応）
- **インターネット接続**: Google Speech Recognition API使用のため

## 🎯 使用方法

1. アプリケーションを起動
2. ブラウザで `http://localhost:5000` にアクセス
3. 「録音開始」ボタンをクリック
4. マイクへのアクセスを許可
5. 話すと自動的に文字起こしが表示されます
6. 「録音停止」ボタンで終了

## 🛠️ 技術スタック

- **バックエンド**: Python Flask + Flask-SocketIO
- **フロントエンド**: HTML5 + CSS3 + JavaScript
- **音声認識**: Google Speech Recognition API
- **リアルタイム通信**: WebSocket (Socket.IO)
- **音声処理**: Web Audio API + MediaRecorder API

## ⚙️ 設定

### 音声認識の精度向上

- 静かな環境で使用
- マイクを口に近づける
- はっきりと話す
- ノイズキャンセリング機能付きマイクの使用を推奨

### トラブルシューティング

**マイクが認識されない場合:**
- ブラウザの設定でマイクアクセスが許可されているか確認
- Windowsのプライバシー設定を確認
- 他のアプリケーションがマイクを使用していないか確認

**音声認識の精度が低い場合:**
- インターネット接続を確認
- 背景ノイズを減らす
- マイクの位置を調整

## 🔒 プライバシー

- 音声データはGoogle Speech Recognition APIに送信されます
- 音声データはローカルに保存されません
- リアルタイム処理のため、音声は一時的にのみ処理されます
